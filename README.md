### 💫 About Me

I am a passionate **Sr. React Native Developer** dedicated to crafting intuitive, performant, and visually engaging cross-platform mobile experiences. With **2.5+ years of hands-on experience** and **10+ production applications delivered**, I bridge the gap between design vision and technical execution.

- 📱 **Primary Focus:** Building scalable, buttery-smooth mobile applications for **iOS & Android** using React Native.
- 🎨 **UI/UX Philosophy:** Obsessed with fluid animations, micro-interactions, responsive layouts, and 60 FPS performance.
- ⚡ **Real-Time Architect:** Proficient in real-time communication using **WebSockets, Socket.io**, and **Firebase**.
- 🛠️ **Production Ready:** Experienced in telemetry, bug tracking via **Sentry**, and end-to-end deployment workflows via **Xcode** & **Android Studio**.
- 📚 **Continuous Learner:** Currently expanding full-stack capabilities with **Node.js**.
